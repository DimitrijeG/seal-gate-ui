Error states

What the console can actually run into. It only builds requests from what it has loaded and checks input before sending, so what is left comes from other people acting at the same time, from permissions it cannot know in advance, or from the server itself.

Caught before sending

Shown as field hints while typing. The request is never sent, so these 400, 413 and 415 answers do not reach the console.

  • ·Secret path with characters outside A–Z a–z 0–9 . _ -, an empty, . or .. segment, or over 256 bytes
  • ·Secret value over 64 KiB, or a generated length outside 16 to 65536 bytes
  • ·Shares or threshold outside 2 to 255, or a threshold above the share count
  • ·Policy name that is not one valid segment; a rule path with * anywhere but the end; a rule with no capability ticked
  • ·Empty username or password, or a password over 1024 bytes
  • ·A pasted share or token that is not valid base64

Not offered at all

Rotate and Revoke are hidden for the root token. Rotate is hidden for a stored secret. The share field is hidden once unsealed, and Initialize once initialized. The console only links to resources it has listed, so it never asks for a path or ID it made up.
